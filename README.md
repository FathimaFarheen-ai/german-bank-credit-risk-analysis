# German Bank Customer Balance Analysis 🏦

A data analysis and machine learning project focused on understanding customer characteristics and classifying customers based on their account balance using Python and Power BI.

## 📌 Project Overview

This project analyzes German Bank customer data to explore relationships between customer demographics, employment characteristics, region and account balance.

A machine learning classification model was developed to identify customers with a high account balance based on selected customer attributes.

The project combines:

- Data cleaning and preprocessing
- Exploratory data analysis
- Machine learning classification
- Model evaluation
- Feature importance analysis
- Power BI visualization

## 🎯 Objectives

- Analyze customer demographic and account information
- Explore customer balance patterns
- Examine relationships between balance and customer characteristics
- Classify customers based on high account balance
- Evaluate the performance of the machine learning model
- Visualize customer and balance insights using Power BI

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest
- Power BI
- Jupyter Notebook

## 📊 Data Analysis

The analysis includes customer attributes such as:

- Gender
- Age
- Region
- Job Classification
- Account Balance

The data was cleaned and prepared for analysis, including conversion of balance values into numeric format and preprocessing of categorical variables.

## 🤖 Machine Learning

A **Random Forest Classifier** was developed to classify customers based on their account balance.

The project uses:

- Feature selection
- Label encoding
- Train-test split
- Random Forest classification
- Predictions
- Accuracy evaluation
- Confusion matrix
- Classification report
- ROC curve and AUC analysis
- Feature importance visualization

The target variable **High Balance** was created based on the customer's account balance.

## 📈 Power BI Dashboard

An interactive Power BI dashboard was created to visualize customer and account-balance insights.

The Power BI `.pbix` file is included in this repository.
